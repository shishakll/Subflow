# 04: 출력 품질 감사 및 충돌 방지 파일 저장기

**What to build:** LLM이 생성한 마크다운 리포트의 구조적 완성도와 타임스탬프 인용 여부를 엄격하게 감사하고, 서로 다른 영상 간 파일명 충돌을 방지하며 마크다운 파일을 저장하고 작업 상태를 `DONE`으로 마킹하는 영속 싱크(Sink).

**Blocked by:** 02: 영속 상태 머신 큐 및 장애 격리 엔진, 03: 프록시 자동 디스커버리 및 가상 슬롯 디스패처

**Status:** ready-for-agent

- [ ] 생성된 노트 본문 길이가 최소 150자 이상인지 검증한다.
- [ ] 5대 필수 섹션 헤더(`### 1.`, `### 2.`, `### 3.`, `### 4.`, `### 5.`)가 모두 포함되어 있는지 확인한다.
- [ ] 본문 내에 정규식 `\[\d{1,3}:\d{2}(?::\d{2})?\]` 형태의 원문 타임스탬프 인용이 최소 1회 이상 존재하는지 검증한다.
- [ ] 동일한 파일명이지만 파일 해시가 다른 기존 완료본이 존재할 경우 `{file_name}_{file_hash[:8]}.md`로 분기하여 파일 덮어쓰기를 방지한다.
- [ ] 디스크 파일 저장이 성공적으로 완료된 후 SQLite 상태를 `status = 'DONE'`으로 원자적 갱신한다.
