# 03: 프록시 자동 디스커버리 및 가상 슬롯 디스패처

**What to build:** 하드코딩된 환경설정 없이 로컬 AI 프록시의 공개 제어면을 통해 접속 정보를 런타임에 자동 획득하고, 1M 컨텍스트 가상 슬롯을 향해 단 1회의 고속 Single-Pass LLM 요청을 전송하는 클라이언트 바인딩 계층.

**Blocked by:** 01: 자막 정규화 및 슬라이딩 윈도우 중복 제거기

**Status:** ready-for-agent

- [ ] 로컬 프록시의 `GET /connect` 엔드포인트를 호출하여 `base_url`, `auth_token`, `default_model` 정보를 3초 타임아웃 이내에 동적 파싱한다.
- [ ] 프록시 미기동 또는 감지 실패 시 로컬 환경변수 기반의 안전 폴백(`http://127.0.0.1:4001/openai/v1`, `gpt-6.1-sol`)으로 전환한다.
- [ ] 업스트림 모델명을 명시하지 않고 가상 슬롯(`gpt-6.1-sol`)으로 지정하여 프록시의 10개 이상 다중 계정 로테이션 및 Fallback 체인을 클라이언트 수정 없이 투명하게 활용한다.
- [ ] 정제된 자막 본문과 학술 연구원 규격 시스템 프롬프트를 포함하여 단 1회의 채팅 완성 요청을 전달한다.
