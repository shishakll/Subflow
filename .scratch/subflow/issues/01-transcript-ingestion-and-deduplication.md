# 01: 자막 정규화 및 슬라이딩 윈도우 중복 제거기

**What to build:** 유튜브 롱폼 영상의 자동 생성 자막(VTT/SRT)에서 시간 경과에 따라 반복되는 롤링 캡션 중복과 스폰서/광고 구간을 로컬에서 결정론적으로 제거하고, 60초 간격의 타임스탬프 앵커(`[MM:SS]`)가 균일하게 삽입된 정제 텍스트를 생성하는 전처리 파이프라인.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] VTT/SRT 타임코드 블록 정규식을 통해 자막 시작/종료 시간과 텍스트를 정확히 파싱한다.
- [ ] 유튜브 비디오 식별자가 주어질 경우 SponsorBlock API를 호출하여 스폰서, 인트로, 아웃트로 구간을 원천 제외한다 (네트워크 지연 시 3초 타임아웃 후 원문 유지).
- [ ] 인접한 자막 라인 간 단순 접두사 일치 및 단어 단위 접미사-접두사(Suffix-Prefix) 최장 공통 부분을 탐색하여 2줄 이상 스크롤되는 롤링 자막 중복을 완벽히 제거한다.
- [ ] 이전 타임스탬프 마커로부터 누적 60초 이상 경과한 시점마다 `\n[MM:SS] ` 형식의 앵커를 텍스트에 삽입한다.
- [ ] 하위 Fallback 모델의 토큰 컨텍스트 한도를 보호하기 위해 최종 정제 텍스트 길이를 안전 상한(400,000자) 이내로 제한한다.
